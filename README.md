# receipt scan

paste a pr, a doc or a chat log, or click the bookmarklet on any page. every zambo receipt link in it (zambo.dev/run/ID, zambo.dev/verify/?id=ID, zambo.dev/api/receipt/ID) is checked live against the aer-1 verify endpoint. only the receipt ids leave your browser. https://zambodotdev.github.io/receipt-scan/

a verified receipt proves the saved bytes are unchanged since the call ran. it does not prove the answer is right.
